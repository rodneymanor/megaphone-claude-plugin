# Megaphone for Claude

This plugin helps you save your content setup and write one script in your own synced Megaphone voice. It uses the Megaphone connector at `https://joinmegaphone.com/mcp`; the plugin contains no credentials or local programs. Add the plugin in Claude, then connect Megaphone from its **Connectors** tab and approve access using your iPhone. Choose **Megaphone Setup** to answer only missing questions. Choose **Megaphone Script** to draft, review, and keep one script. Open Megaphone on your iPhone to import a kept script into your library. A queued delivery is not yet a saved library script.

The plugin reads your Megaphone account, confirmed content bank, custom voice readiness, and synced script library. With your answers, it saves setup versions. When you ask for a script, it uses the Megaphone backend to generate a draft. It sends a script to your phone only after you keep the final text. You can disconnect Megaphone from Claude's connector settings.
